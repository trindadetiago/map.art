# map.art

Pixel-art map tool.

## Apps

- `apps/web` - UI, API, debug pages

## Packages

- `db` - projects, tiles, models
- `env` - typed env
- `models` - image models
- `renderer` - tile render
- `shared` - shared types
- `storage` - file storage
- `tiles` - tile math

## Dev

```bash
pnpm install
pnpm dev
```
